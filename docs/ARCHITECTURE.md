# Independent POF OS Architecture
Approved direction 2026-11-23; implementation NOT TESTED.
Next.js/React/TypeScript/Prisma/PostgreSQL existing stack. POF owns permanent internal IDs, catalog, order state, immutable price snapshots and payment records. Provider mappings are optional, scoped by merchant/location/provider. Clover migration is read-only initially; never run destructive legacy importer against production.
Website and counter POS share server-validated catalog and order service. Payment adapter uses certified processor, verified webhooks, idempotency and reconciliation. Durable order/outbox precedes acknowledgment; KDS and edge consume idempotently. Edge Ubuntu service handles local cash orders and printing with durable queue, restart recovery and explicit ambiguous-print reconciliation. No raw card data. Supabase Auth/Realtime and edge components are targets, not verified installations. Preserve existing menu boards and marketing fallback; fallback never prices checkout. No dual fulfillment. Keep Clover/Menufy until separate cutover approval.
Detailed schemas, dependencies, tax settings and processor selection require applicable AGENTS.md approval.
